Herramientas open source

▣ aqueductus public
github.com/RemoYukoff/aqueductus ↗

Framework open source para testing de datos: valida datasets y outputs de pipelines usando SQL sobre múltiples data sources, con configuración declarativa en YAML. 


# aqueductus.yml
sources:
  warehouse:
    type: postgres
    dsn:  ${WAREHOUSE_DSN}

tests:
  - name: no orphan orders
    query: |
      SELECT COUNT(*) FROM orders o
      LEFT JOIN customers c ON c.id = o.customer_id
      WHERE c.id IS NULL
    expect: { rows: 0 }
Python YAML SQL Data Quality
